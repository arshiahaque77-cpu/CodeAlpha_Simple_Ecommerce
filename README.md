# Simple E-Commerce Store (Django)

A full-stack e-commerce web application built with Django, featuring secure user authentication, product catalogs, shopping cart management, and order checkout workflows. Developed as part of the CodeAlpha Python/Django Internship.

## 🚀 Features
* **User Authentication:** Secure registration, login, and session-based logout flows.
* **Product Catalog:** Dynamic product listings and detailed views.
* **Shopping Cart:** Add, update, and manage items in real-time with session persistence.
* **Order Processing:** Seamless checkout workflow linked to user accounts.
* **Minimalist UI:** Styled cleanly using Pico CSS for a modern, responsive interface.

## 🛠️ Tech Stack
* **Backend:** Python, Django
* **Database:** SQLite
* **Frontend:** HTML5, Pico CSS
* **Version Control:** Git & GitHub
